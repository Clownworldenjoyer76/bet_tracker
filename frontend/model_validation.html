Predicted probability (blue bar) Actual win rate (green bar)

The model assigns a probability to each bet before the game is played. For example, "this team has a 65% chance to cover."

Calibration measures whether those predictions are accurate in reality. If the model says 65% and teams actually win 65% of the time in that bucket — the model is perfectly calibrated.

If it predicts 65% but they only win 50%, the model is overconfident. If they win 75%, it's underestimating.

The bars show predicted probability in blue and actual win rate in green. If these align closely across all buckets, the model's confidence levels are trustworthy — not just that it wins bets.
