Definitions

fair_decimal_moneyline:
    True probability converted to decimal odds (no vig)

juiced_decimal_moneyline:
    Fair odds adjusted using config (contains synthetic vig)

juiced_prob_moneyline:
    1 / juiced_decimal (raw implied probability BEFORE normalization)

normalized_prob_moneyline:
    juiced_prob scaled so:
        home + away = 1 exactly

# JUICED (RAW)
over_juiced_decimal_total
under_juiced_decimal_total

over_juiced_prob_total

# NORMALIZED
over_normalized_prob_total
under_normalized_prob_total

Definitions

total:
    Game total line (e.g., 6.5)

fair_total_*_decimal:
    Fair odds for over / under

juiced_prob_total:
    Probability after juice applied (pre-normalization)

normalized_prob_total:
    Final probability such that:
        over + under = 1

GLOBAL COLUMN RULES (IMPORTANT)

1. "fair_*"
   → no vig, model-derived probability

2. "juiced_*"
   → includes synthetic vig from config

3. "normalized_*"
   → guaranteed valid probability distribution
   → ALWAYS sums to 1 within market

MARKET STRUCTURE SUMMARY

MONEYLINE:
    juiced_prob ≠ sum to 1
    normalized_prob = final usable probabilities

PUCK LINE:
    juiced_prob = already normalized
    normalized_prob = duplicate (for schema consistency)

TOTAL:
    juiced_prob ≠ sum to 1
    normalized_prob = final usable probabilities

CRITICAL ASSUMPTIONS (FOR DEBUGGING)

- All probabilities must be between 0 and 1
- Normalized columns must sum to 1 per row
- Favorite must always have higher probability
- No column should contain NaN after processing
- Decimal odds must always be > 1

TL;DR

Use normalized_prob_* for any modeling or evaluation.

juiced_prob_* exists to:
    - inspect raw vig impact
    - calculate hold
    - debug config behavior

Do NOT assume juiced_prob sums to 1 (except puck line).
