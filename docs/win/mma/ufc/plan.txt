Clean roadmap
Phase 1

Use only:

dratings probabilities
sportsbook odds
result

Build baseline predictive model.

Phase 2

Add rolling fighter history features.

Phase 3

Add outside stats later:

age
reach
stance
significant strike differential
takedown stats
layoff days
promotion level

That is where it can get much stronger.

My recommendation

Start with odds + dratings + rolling fighter history.

That is the best balance of:

easy to build
interpretable
actually useful

Do not start with just fighter name.
Do not start with a giant all-purpose system.

Start with a fight-level CSV master, engineer features, train logistic regression, then move to XGBoost.
