### Step 2 — New script: `enrich_game_context.py` (runs after `scrape_mlb_raw.py`)

This script runs per game day and builds a **game context file** at `00_intake/mlb_raw/{date}_game_context.csv`.

It joins these sources using the mlb_raw file as the spine:

**From `maps/`:**
- `mlb_venue_ids.csv` → `roof_type`, `turf_type`, `latitude`, `longitude`, `time_zone_id`
- `mlb_team_ids.csv` → team names for matching
- `mlb_pitcher_ids.csv` → pitcher hand (L/R) per game
- `mlb_batter_ids.csv` → bat side per lineup slot

**From Statcast batting/pitching files** (join on `player_id`):
- Priority: 2026 current season → fall back to 2025 → fall back to 2020-2024 weighted average
- For each **starting pitcher**: pull `k_percent`, `bb_percent`, `xwoba`, `barrel_batted_rate`, `hard_hit_percent`, `whiff_percent`, `exit_velocity_avg`
- For each **lineup batter** (positions 1-9): pull `xwoba`, `barrel_batted_rate`, `hard_hit_percent`, `k_percent`, `bb_percent`, `exit_velocity_avg`
- Aggregate lineup stats into **home_lineup_xwoba**, **away_lineup_xwoba**, etc. (simple mean of the 9 batters)

**From Fielding Run Value:**
- Join on player id → pull `total_runs` for each batter in lineup, aggregate as **home_lineup_frv**, **away_lineup_frv**

**From Baserunning Run Value:**
- Join on player id → pull `runner_runs_tot`, aggregate as **home_lineup_brv**, **away_lineup_brv**

**From Park Factors:**
- Use `roof_type` from venue map to select condition (Roof Closed vs. Open Air)
- Use `day_night` from mlb_raw to select Day vs. Night
- For bat side: use `Both` files for the team-level park factor (individual batter matching is possible later)
- Pull: `Park Factor`, `wOBAcon`, `HR`, `R` for the venue

**From Weather API:**
- Use `latitude`/`longitude` from venue map + `game_time` + `day_night`
- Pull: `temperature`, `wind_speed`, `wind_direction`, `precipitation`, `humidity`
- Skip for indoor/roof-closed venues

### Step 5 — Modify `compute_edges.py`

After computing raw edges, apply **park and weather adjustments**:

- **Park Factor**: scale `home_edge` by `(park_factor / 100)` directionally. High park factor (hitter-friendly) lifts over/home totals, suppresses pitcher-side edges.
- **Wind**: if `wind_speed > 15 mph` and `wind_direction` is blowing out, add a small positive nudge to over edges. Blowing in → under nudge. Dead air or indoor → no adjustment.
- **Temperature**: below 50°F suppresses offense slightly. Above 80°F boosts it.
- **SP quality matchup**: compute `sp_edge = home_sp_xwoba - away_sp_xwoba` as a signal. Feed into adjusted probability rather than just raw model prob.
- **Lineup xwOBA differential**: `lineup_edge = home_lineup_xwoba - away_lineup_xwoba`. Use as a secondary adjustment on moneyline and run line.

These don't replace the Skellam/Poisson model — they're **multipliers or additive adjustments** on the edges already computed, keeping your existing math intact.
